Sobre o projeto

Este projeto consiste em um portfólio pessoal desenvolvido como atividade prática, utilizando HTML, CSS, JavaScript e Bootstrap 5.

O objetivo é apresentar minhas habilidades, conhecimentos e projetos na área de tecnologia.

Tecnologias utilizadas

HTML5

CSS3

JavaScript

Bootstrap 5

Componentes do Bootstrap utilizados

Navbar: menu de navegação.

Cards: apresentação de habilidades e projetos.

Buttons: botões de navegação e ações.

Forms: formulário de contato.

Outros recursos utilizados

Sistema de Grid (container, row e col).

Classes de cores e tipografia.

Classes de espaçamento.

Imagens responsivas (img-fluid).

Como executar

Basta abrir o arquivo index.html em um navegador.
